# ADR-0007 — Feature flags via `platform_settings/modules`

- **Status:** Aceito
- **Data:** 2026-09-05

## Contexto
A FLOW precisa ativar/desativar módulos sem deploy.

## Problema
Escolher o mecanismo de feature flags.

## Opções
1. Env vars estáticas.
2. Firestore `platform_settings/modules` + `ModuleGate`.
3. Serviço externo (LaunchDarkly/Unleash).

## Decisão
**Opção 2** — flags por módulo persistidas no Firestore, gerenciadas pelo admin (`ModuleCenter`), aplicadas via `ModuleGate` no roteador, com auditoria em `admin_audit`. `useModuleStates` faz fail-open em erro.

## Consequências
- Positivas: sem dependência externa, auditável, tempo real.
- Negativas: `disabled` ainda não bloqueia rotas (apenas `maintenance`).
- Mitigação: evoluir para flags de feature com rollout (ver `30-FEATURE-FLAGS.md`).

## Alternativas rejeitadas
- Serviço externo agora: complexidade sem necessidade.
- Env estática: exige deploy para mudar estado.
