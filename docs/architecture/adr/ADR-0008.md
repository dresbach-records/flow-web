# ADR-0008 — Light UI como padrão único

- **Status:** Aceito (decisão de produto)
- **Data:** 2026-09-05

## Contexto
`main.tsx` força `data-theme=light` e remove `flow.theme`.

## Problema
Suportar dark mode ou manter Light UI único?

## Opções
1. Light + Dark com toggle.
2. Light UI único.

## Decisão
**Opção 2 — Light UI único.** O produto adota a paleta clara; temas escuros foram removidos.

## Consequências
- Positivas: consistência visual, menos CSS, foco.
- Negativas: usuários que preferem dark não são atendidos.
- Mitigação: reavaliar quando houver demanda/recursos (tokens já suportam temas).

## Alternativas rejeitadas
- Dark mode agora: aumentaria superfície de manutenção no estágio atual.
