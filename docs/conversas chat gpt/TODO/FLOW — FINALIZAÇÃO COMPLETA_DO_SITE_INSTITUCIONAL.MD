A HOME DO SITE DA FLOW JÁ FOI CRIADA E DEVE SER TRATADA COMO A REFERÊNCIA VISUAL OFICIAL DO SITE.

NÃO recrie a identidade visual.
NÃO invente outro layout.
NÃO altere arbitrariamente cores, tipografia, espaçamentos, botões, header ou footer.

32. CRITÉRIO FINAL

O SITE NÃO ESTARÁ FINALIZADO SE:

- somente a HOME estiver bonita;
- outras páginas estiverem vazias;
- links estiverem quebrados;
- botões não funcionarem;
- formulários forem falsos;
- houver mock;
- houver páginas static para funcionalidades;
- houver CSS duplicado;
- Header estiver duplicado;
- Footer estiver duplicado;
- páginas possuírem identidades visuais diferentes.

O SITE ESTARÁ FINALIZADO QUANDO TODAS AS PÁGINAS POSSUÍREM A MESMA ESSÊNCIA VISUAL DA HOME E ESTIVEREM INTEGRADAS À APLICAÇÃO REAL.

A HOME É A REFERÊNCIA.

O RESTANTE DO SITE DEVE SER UMA EXTENSÃO NATURAL DELA.

O resultado deve parecer um único produto FLOW, e não várias páginas desenvolvidas separadamente.
